# VISION.md

## Objective
To transition this project from a static **Blender Animation Generator** (which simply applies animations to a default model on a flat grey plane) into an autonomous, end-to-end **Movie Generation Engine** that takes arbitrary user scripts and generates coherent, high-fidelity cinematic outputs.

## Key Goals
1. **Dynamic Environment Composition**: Location strings dynamically generate unique terrains, skies, lighting, atmosphere, and procedural assets (forests, castles, mountains, etc.).
2. **Dynamic Asset Registry**: Story nouns (weapons, armor, items, creatures) are parsed and dynamically loaded, positioned, and attached to characters or scenes.
3. **Visual Continuity**: Dynamic states (held items, visual modifications, weather, locations) persist consistently across consecutive scenes.
4. **Cinematic Camera & Lighting**: An automated camera director decides shot types, framing, angles, and light colors/shadows to match scene mood.
5. **Semantic Understanding**: Advanced script analysis capable of rendering complex, abstract, and emotional narratives rather than just basic keyword verbs.
